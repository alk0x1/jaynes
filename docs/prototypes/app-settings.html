What the first version holds

Only what the app already applies, or does with a few lines. Saved in ~/.jaynes/app-settings.json; a missing or broken file falls back to these defaults.

In

  • Terminal colors: Jaynes (default), Graphite, Ink, Moss. The terminal's palette.
  • Terminal font and size: the bundled monospace fonts (IBM Plex Mono, JetBrains Mono, Geist Mono) and any installed; 14 by default.
  • Option key: Auto (today's: Alt on U.S. and ABC keyboards, so Option-arrow still moves a word; special characters on other layouts), Alt, Left Alt only, or Characters.
  • Copy on select: on by default.
  • Scroll speed: 1.0× by default.
  • Notifications: when an agent needs you or finishes (on). Wired in a few lines.
  • New agent runs: what Command-T starts, claude by default; it starts in the open agent's folder, as today.
  • Editor: what e in Changes opens; empty means $VISUAL, then $EDITOR, as today.

Out, and why

  • Light theme, follow the system: only the terminal would turn light; the window around it is drawn dark. Needs the window's own light colors first.
  • Sounds: the app plays none yet.
  • Zoom: no zoom keys yet, and it would only scale the terminal, the same as font size.
  • Default folder for new agents: a new agent starts in the open agent's folder; a fixed folder would undo that.
  • Look (Familiar · Buffer · Window): only Familiar is built. Show it with the other two as "coming soon", or leave it out until they exist?
