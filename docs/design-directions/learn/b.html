Your agent says done.

You give an agent a task. It works for twenty minutes, takes two hundred actions, and says: done. Did it follow the process? Did it skip the part where it should have asked you? You have two options, and both are bad.

Action: one thing an agent does, like reading a file, editing one, or running a command. Claude Code calls them tool calls.
