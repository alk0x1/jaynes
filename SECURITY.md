# Security

To report a vulnerability, use **Report a vulnerability** in this repository's Security tab: the report reaches
only the maintainer. Never report one in a public issue.

You get a first answer within 14 days.

What the engine guarantees, and what it does not, is written in [docs/guarantees.md](docs/guarantees.md). How far
the box around a step goes is said in its last section,
[What this page does not promise](docs/guarantees.md#what-this-page-does-not-promise): read it before you rely on
the box.
