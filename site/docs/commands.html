Commands

Every jaynes command. Your agent uses them for you; you rarely need them.

CommandWhat it does
jaynes start --role NAME --project DIR --request TEXT [--risk high]Starts a run and drives it until it needs someone
jaynes show RUN, jaynes runsWhere a run is; every run
jaynes page [--port N]The page, on 127.0.0.1 (port 8750)
jaynes answer RUN QUESTION [ITEM=keep|change:TEXT|redo:TEXT|drop|skip] [--context TEXT] [--send]Says what an answer will do, and sends it with --send; from a terminal it is yours, from a program an agent's
jaynes continue RUNGoes on after a block, or after the process stopped
jaynes halt RUN, jaynes resume RUNHalts a run before its next step; only you resume it
jaynes raise RUN high, jaynes raise RUN --seconds N --tokens NRaises a run's risk or its ceiling
jaynes abandon RUN, jaynes undo RUNEnds a run with nothing delivered; reverts what it merged
jaynes correct RUN --note TEXT [--step STEP]Records that a delivery was wrong, so the rework counts
jaynes costWhat finished runs cost, by risk, with what was sent back and corrected
jaynes verify, jaynes log RUNWhether the record holds; a run's entries
jaynes add SOURCE, jaynes remove NAME, jaynes rolesInstalls, removes and lists roles
jaynes conformance DIR, jaynes schemaChecks a role against the protocol; prints the protocol's schema
jaynes guide, jaynes updateHow an agent uses Jaynes; installs the newest Jaynes, its plugin and roles from git
jaynes mcp, jaynes permitThe servers Claude Code starts: tools for agents, and the leave server of a turn
