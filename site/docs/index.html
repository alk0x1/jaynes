Get started

Jaynes runs your agent through a method one step at a time, checks each step by code, and asks you only where your judgment is still needed. You install it once; after that you work in Claude Code as usual and answer on a page on your computer.

Install

Type this in Claude Code, answer y to add the marketplace, and press Enter to install it for your user:

/plugin install jaynes --marketplace alk0x1/jaynes

The first time your agent uses it, the agent installs the jaynes command, built with Rust's cargo (install Rust with rustup if you have none). Roles written in Python need python3. Jaynes runs on macOS; Linux is next.

From a terminal, without the plugin:

cargo install --locked --git https://github.com/alk0x1/jaynes jaynes-shell --root ~/.local
jaynes add https://github.com/alk0x1/jaynes#engine/roles/small-change
jaynes add https://github.com/alk0x1/jaynes#engine/roles/fix-bug
jaynes guide

Work as usual

Talk the change through with your agent and approve the plan: "go ahead", "do it". The agent hands it to Jaynes by itself: it picks a role, the method for that kind of work, and starts a run with the whole plan as its request. The run goes on by itself.

Say "with Jaynes" to send any task through it, or "without Jaynes" for one the agent should make itself.

Answer where the run needs you

A stop is a point in the method where your judgment matters. Most stops do not hold the run: it goes on and delivers, and your answer, given later, corrects it. What cannot be undone waits for you. You answer on the page, which Jaynes opens in your browser at http://127.0.0.1:8750.

Part of the pageWhat it shows
Waiting for youEvery open question across your runs, and whether its run waits for it or goes on
A questionIts items, each with a sentence and pictures when the role gives them, a verdict per item, one line of context, and what your answer will do, written by Jaynes before you send it
Let through by an agentResults an agent let go on at a stop the role marks as a release; you can still change them
RunsEach run's steps, what it spent and what blocks it, with Halt, Resume, Continue, Raise, Abandon, Undo and Correct

Only a browser that opened the page's link with its key answers as you. Anything else, such as an agent calling the page, counts as an agent.

The guard

The plugin also brings a guard to every Claude Code session: before a git or GitHub action that cannot be undone, such as a push, a hard reset or a deleted branch, it asks you.

What Jaynes promises

Seventeen sentences, such as "something you kept stays as it is unless you change it", each tested on thousands of random runs; twelve are proved in Lean for a model of the core that a test compares with the code. Read them.
